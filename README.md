🍕 Pizza Sales Analysis using SQL

A SQL-based data analysis project that explores a pizza restaurant's sales data to uncover key business insights such as revenue, customer ordering patterns, popular pizzas, and sales trends.

---

## 📌 Project Overview

This project analyzes pizza sales data using SQL queries to answer important business questions. The objective is to transform raw transactional data into meaningful insights that can help improve sales strategies and business decisions.

---

## 🎯 Objectives

- Calculate total revenue generated
- Find the total number of orders
- Identify the most ordered pizza size
- Determine the top-selling pizza types
- Analyze hourly order distribution
- Calculate average pizzas ordered per day
- Identify the highest revenue-generating pizzas

---

## 🛠️ Tools & Technologies

- SQL

- JOIN Operations
- Common SQL Functions

---

## 📂 Database Tables

- **orders**
- **order_details**
- **pizzas**
- **pizza_types**

---

## 📊 Business Questions Solved

1. Retrieve the total number of orders placed.
2. Calculate the total revenue generated from pizza sales.
3. Identify the most commonly ordered pizza size.
4. Determine the distribution of orders by hour of the day.
5. List the top 5 most ordered pizza types along with their quantities.
6. Find the top 3 pizza types based on revenue.
7. Calculate the average number of pizzas ordered per day.

---

## 📈 Key Insights

- **Total Orders:** 21,350
- **Total Revenue:** $817,860.05
- **Most Ordered Pizza Size:** Large (L)
- **Top Revenue-Generating Pizza:** Thai Chicken Pizza
- Peak ordering hours were identified through hourly sales analysis.
- Average daily pizza orders were calculated to understand customer demand.
